## 0. 一次性配置：把命令变短（强烈建议）

整段复制粘贴到服务器终端一次即可：

```bash
cat >> ~/.bashrc <<'EOF'

# ===== 机械臂项目快捷命令 =====
alias ws='cd ~/robot_vla_ws'
alias sb='source ~/robot_vla_ws/install/setup.bash'
alias sim='ros2 launch rm_bringup rm_eco65_gazebo.launch.py'
alias killgaz='killall -9 gzserver gzclient'
alias js='ros2 topic echo /joint_states'
alias tfe='ros2 run tf2_ros tf2_echo baselink Link6'
alias fk='python3 ~/robot_vla_ws/src/arm_control/scripts/fk_check.py'
alias ik='python3 ~/robot_vla_ws/src/arm_control/scripts/ik_check.py'
alias model='python3 ~/robot_vla_ws/src/arm_calibration/scripts/check_model.py'
alias pidlab='python3 ~/robot_vla_ws/src/arm_control/scripts/pid_lab.py'
alias pidtrack='python3 ~/robot_vla_ws/src/arm_control/scripts/pid_track.py'
alias urdf='xacro ~/robot_vla_ws/src/ros2_rm_robot/rm_description/urdf/rm_eco65.urdf link6_type:=Link6_6fb > /tmp/eco65_6fb.urdf'
# 提交代码：gp "提交说明"
gp() { cd ~/robot_vla_ws && git add -A && git commit -m "$1" && git push; }

# ---- P4 视觉 / 手眼（2026-10-20 新增）----
alias simcam='pkill -9 Xvfb; sudo rm -f /tmp/.X*-lock /tmp/.X11-unix/X*; xvfb-run -a -s "-screen 0 1280x1024x24" ros2 launch ~/robot_vla_ws/src/arm_perception/launch/camera_demo.launch.py'
alias box='ros2 run gazebo_ros spawn_entity.py -file ~/robot_vla_ws/models/target_box/model.sdf -entity target_box'
alias camtopic='ros2 topic list | grep wrist_depth'
alias seegreen='python3 ~/robot_vla_ws/src/arm_perception/scripts/see_green.py'
alias camwhere='python3 ~/robot_vla_ws/src/arm_perception/scripts/camera_where.py'
alias posesearch='python3 ~/robot_vla_ws/src/arm_perception/scripts/pose_search_green.py'
alias boxloc='python3 ~/robot_vla_ws/src/arm_perception/scripts/box_localize.py'
EOF
source ~/.bashrc
```

配置后可用：`ws` `sb` `sim` `killgaz` `js` `tfe` `fk` `ik` `model` `pidlab` `pidtrack` `urdf` `gp "说明"`。

## 5. 让机械臂动起来

**回零位**（最常用，调试前先做）：

```bash
ros2 action send_goal /rm_group_controller/follow_joint_trajectory control_msgs/action/FollowJointTrajectory "{trajectory: {joint_names: [joint1,joint2,joint3,joint4,joint5,joint6], points: [{positions: [0,0,0,0,0,0], time_from_start: {sec: 3, nanosec: 0}}]}}"
```

**单关节转动**（把 positions 里对应位改成角度，单位弧度）：

```bash
ros2 action send_goal /rm_group_controller/follow_joint_trajectory control_msgs/action/FollowJointTrajectory "{trajectory: {joint_names: [joint1,joint2,joint3,joint4,joint5,joint6], points: [{positions: [0,0,0,0,0,0.3], time_from_start: {sec: 3, nanosec: 0}}]}}"
```

> 关节顺序固定：`joint1` ~ `joint6`。转动方向口诀：基座转水平、肩肘管高度、腕 6 只转姿态不挪位置。

**PID 相关**：

| 目的 | 命令 |
|------|------|
| 单关节 PID 数学实验 | `pidlab` |
| PID 闭环接 Gazebo 轨迹跟踪 | `pidtrack` |

## 7. 排错速查（报错 → 原因 → 解决）

| 报错 | 原因 | 解决 |
|------|------|------|
| `404 Not Found`（装 ROS 时） | apt 索引过期 | `sudo apt update` 后重试；仍失败换腾讯源（见 README） |
| `No module named 'xacro'` | 缺 xacro | `sudo apt install -y ros-foxy-xacro` |
| `Failed to load plugin libgazebo_ros2_control.so` | 缺 ros2_control | `sudo apt install -y ros-foxy-gazebo-ros2-control ros-foxy-ros2-control ros-foxy-ros2-controllers` |
| `Invalid frame ID "base_link" ... does not exist` | 帧名错了 | 用 **`baselink`** 和 **`Link6`** |
| `Address already in use` / `Entity already exists` | 上次仿真残留 | `killgaz` 后重启 |
| `ros2: error: unrecognized arguments: --version` | Foxy 无此参数 | 用 `echo $ROS_VERSION` 或 `ros2 --help` |
| `ros2 topic echo --once` 报错 | Foxy 无 `--once` | 直接 `ros2 topic echo <话题>`，Ctrl+C 退出 |
| `Unable to locate package ros-foxy-xxx` | 镜像未收录 | 腾讯镜像不全，换方案（如纯 numpy 自研，见 README） |
| `InvalidHandle`（Ctrl+C 时） | rclpy 关闭顺序 | 无害，忽略 |
| PID 误差突然巨大 | ①角度环绕 ②控制器状态损坏 | ①误差要 wrap ②`killgaz` 重启仿真 + 先回零 |
| `Xvfb failed to start` | 上次虚拟屏残留锁文件 | `pkill -9 Xvfb; sudo rm -f /tmp/.X*-lock /tmp/.X11-unix/X*`，之后都用 `xvfb-run -a`（自动选空闲编号） |
| `gzserver ... exit code 137` | 被系统 OOM 杀掉 | 同时跑了两个仿真；一次只跑一个 |
| 查 `/camera/image_raw` 报 WARNING | Foxy 话题前缀是**传感器名** | 实际是 `/wrist_depth_camera/image_raw` |
| `点云非结构化(height<=1)` | Foxy 深度相机点云是一维长条 | 已改用行优先索引 `idx = v*width+u` |
| `Lookup would require extrapolation into the past` | 点云戳(仿真时钟) vs TF(墙钟) 不一致 | 已改用取最新 TF；长期正解统一 `use_sim_time:=true` |
| 方块在视野里却测不到 / 角度达标但绿色 0% | 方块被撞走了（真实物理），位置假设失效 | 用 `posesearch`（绿色占比为准，不依赖位置假设） |

## 8. 标准开工流程（每天照做）

```bash
sb                 # 1 加载环境
killgaz            # 2 清残留（如需）
sim                # 3 启动仿真（终端 A）
# 新开终端：
js                 # 4 确认关节数据在动
tfe                # 5 确认 TF 正常
# 干活……
gp "提交说明"       # 6 收工推送
```
