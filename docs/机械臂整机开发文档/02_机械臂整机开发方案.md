# 睿尔曼 ECO65 六维力版机械臂智能抓取（VLA）整机开发方案

> 目标：一台能「听懂话 + 看场景 + 自主抓取」的机械臂整机。
> 硬件：睿尔曼（RealMan）ECO65-6FB 六轴机械臂（六维力版）+ 二指/V 型电动夹爪 + 四目深度相机。
> 软件：Ubuntu 20.04 + ROS2 Foxy + 官方 `ros2_rm_robot` 包 + OpenPI VLA 模型。
> 控制：**底层 PID 精确执行 + 高层 OpenPI VLA 决策** 双层架构。

---

## 一、一句话说清整体思路

整机 = 把大工程拆成「官方包（复用）+ 自定义包（新增）」两类，接口先行、仿真优先、一个模块一个模块点亮。

**关键变化**：相比上一版「通用 6 关节」，这次机械臂锁定 ECO65 六维力版、ROS 锁定 Foxy，并加入 VLA 模型。控制分两层：

```
高层（聪明的大脑）：OpenPI VLA —— 看图像 + 听语言指令 → 决定「手往哪动、夹爪怎么动」
底层（听话的肌肉）：PID 控制 —— 把 VLA 的决定精确执行到位
```

> 大白话：VLA 负责「想做什么」，PID 负责「把动作做准」。两者分工，缺一不可。

## 二、ECO65 六维力版（ECO65-6FB）机械臂实参

### 2.0 一句话认识这款臂

- 睿尔曼 ECO 系列里的中等尺寸协作臂，**六维力版在末端内置六维力传感器**。
- 核心指标：有效负载 **5 kg**、工作半径 **627 mm**、重复定位精度 **±0.05 mm**、自重 **7.9 kg**。

### 2.1 六维力传感器（本版核心，抓取项目的关键）

| 指标 | 数值 |
|------|------|
| 量程 | 200 N / 7 N·m |
| 精度 | ±0.5% FS |

对我们有什么用（后文会反复用到）：
1. **拖动示教**：直接手拽机械臂录轨迹，是采集 VLA 示教数据最自然的方式。
2. **力控**：恒力贴合、柔顺插入，抓取/放置更稳。
3. **夹爪力反馈**：感知夹持力，防止夹碎或夹不住。
4. **碰撞检测**：多一层安全。

> 注意：更换六维力末端后，必须重新标定六维力的初始力与重心（官方说明书明确要求）。

### 2.2 关节结构（6 个全旋转关节）

| 关节 | 限位（弧度） | 约等于（度） | 最大速度 | 力矩上限 |
|------|-------------|-------------|---------|---------|
| J1（基座旋转） | ±3.106 | ±178° | 3.14 rad/s（180°/s） | 60 N·m |
| J2（肩） | −3.106 ~ 2.356 | −178° ~ 135° | 3.14 rad/s | 60 N·m |
| J3（肘） | −2.792 ~ 2.53 | −160° ~ 145° | 3.14 rad/s | 30 N·m |
| J4（腕1） | ±3.106 | ±178° | 3.14 rad/s | 10 N·m |
| J5（腕2） | ±3.106 | ±178° | 3.14 rad/s | 10 N·m |
| J6（腕3） | ±6.28 | ±360° | 3.14 rad/s | 10 N·m |

> **实测修正（2026-10-19 从官方 URDF 读出）**：最大速度并非统一值——**J1~J3 = 3.14 rad/s（180°/s），J4~J5 = 3.92 rad/s（225°/s）**（J6 待确认，按说明书应为 225°/s）。
> 力矩：URDF 里 `effort` 统一写 **100 N·m**（比手册的 60/30/10 粗略保守），**安全限速以 URDF 为准**。
> 关节与连杆命名（写代码必须照抄）：**`joint1`~`joint6`**、**`baselink` → `Link1`~`Link6`**（无下划线，`Link` 首字母大写）。

### 2.3 连杆尺寸（URDF 关节原点，单位米）

```
base → J1  0.1625（底座高度）
J1 → J2    X −0.086
J2 → J3    X 0.260（上臂）
J3 → J4    X 0.240（前臂）、Z −0.0589
J4 → J5    Y −0.110
J5 → J6    Y 0.0795
```

### 2.4 MDH 参数（改进 D-H，说明书提供，供运动学模块直接用）

| i | a_{i−1} | α_{i−1} | d_i | 零位偏移 |
|---|---------|---------|-----|---------|
| 1 | 0 | 0 | 162.5 mm | 0 |
| 2 | −86 mm | −90° | 0 | −90° |
| 3 | 260 mm | 0 | 0 | 90° |
| 4 | 240 mm | 0 | −58.9 mm | 90° |
| 5 | 0 | 90° | 110 mm | 0 |
| 6 | 0 | −90° | 96.7 mm（6FB） | 0 |

> d6 随版本不同：标准版 B = 79.5 mm，**六维力版 6FB = 96.7 mm**，六维力 K 版 6F = 108 mm。

### 2.5 质量（URDF 已提供，供动力学模块直接用）

| 连杆 | 质量（kg） |
|------|-----------|
| base_link | 0.705 |
| link_1 | 0.789 |
| link_2 | 1.380 |
| link_3 | 1.036 |
| link_4 | 0.273 |
| link_5 | 0.313 |
| link_6 | 0.065 |

连杆 1~6 合计约 **3.86 kg**（结构件）；整机自重 **7.9 kg**（说明书，含电机/减速器/六维力传感器）。

### 2.6 末端法兰与底座（安装夹爪 / 六维力传感器 / 固定机身）

- **末端法兰**：直径 φ57 mm，6×M4-6H 螺纹孔（镶嵌 304 钢丝牙套）+ 4×H7 定位孔 + 8×φ2.8 通孔，材质 6061-T6（六维力传感器即装在此法兰上）。
- **底座**：4×φ6.5 安装孔，孔距 94×47 mm，外径 φ110 mm，材质 6061-T6。
- **末端对外接口**：6 芯航插 = RS485 + 2 路数字 IO + 电源输出 12V/24V（最大 1.5 A），可直接给夹爪供电并控制。

### 2.7 通信（已确认）

- 主通信：以太网（有线网口）+ JSON 协议；另有 WiFi / USB / RS485 / Modbus-RTU-TCP。
- 透传周期：第三代控制器最快 5 ms（适合做动态轨迹规划与视觉伺服）。

### 2.8 待确认（剩余）

| 待确认项 | 影响 |
|---------|------|
| 夹爪型号（睿尔曼官方 or 自配 V 型二指） | 决定夹爪接口与力反馈 |
| GPU 型号 | VLA 训练/推理可行性 |
| 四目深度相机具体型号（有无 ROS 驱动） | 决定视觉模块工作量 |
| 仿真用 Gazebo 还是 Webots | 建议 Gazebo（官方开箱即用） |

## 三、系统总体架构（双层控制 + 数据流）

### 3.1 数据流（与 OpenPI VLA 计划书一致）

```
自然语言指令 + 摄像头图像 + 机械臂当前状态
              ↓
        OpenPI VLA 模型
              ↓
      机械臂动作序列（末端位姿增量 + 夹爪动作）
              ↓
         ROS 控制节点（PID 底层执行）
              ↓
        机械臂（ECO65-6FB）+ 夹爪
              ↓
         完成抓取与放置
```

### 3.2 分层

```
┌──────────────────────────────────────────┐
│ 应用层    抓取/放置流程编排               │
├──────────────────────────────────────────┤
│ 决策层    OpenPI VLA（看 + 听 → 生成动作）│
├──────────────────────────────────────────┤
│ 感知层    四目深度相机 → 点云 → 目标位姿  │
├──────────────────────────────────────────┤
│ 控制层    PID 关节/笛卡尔控制 + MoveIt    │
├──────────────────────────────────────────┤
│ 算法层    FK / IK / 动力学 / 手眼标定     │
├──────────────────────────────────────────┤
│ 驱动层    官方 rm_driver + rm_control     │
├──────────────────────────────────────────┤
│ 硬件层    ECO65 本体 + 夹爪 + 相机        │
└──────────────────────────────────────────┘
```

> 蓝色三层（算法、控制、驱动）是「把动作做准」的部分；感知 + 决策是「决定做什么」的部分。

## 四、软件环境与官方包（ROS2 Foxy）

### 4.1 环境

- Ubuntu 20.04 + ROS2 Foxy（官方 `ros2_rm_robot` 明确只支持 Foxy，勿升级 Humble/Jazzy）。
- NVIDIA GPU + CUDA + PyTorch（OpenPI 推理需要，建议独立 conda/uv 环境，与 ROS 解耦）。
- 官方包版本 v1.7.0，对应机械臂控制器固件 1.7.3。

### 4.2 官方包清单（复用，不重写）

| 官方包 | 作用 |
|--------|------|
| `rm_install` | 一键装 ROS2 / MoveIt2 脚本 |
| `rm_driver` | 底层驱动（订阅/发布关节状态与指令） |
| `rm_description` | ECO65 URDF 模型 + 坐标系变换 |
| `rm_ros_interfaces` | 官方消息/服务/动作接口 |
| `rm_bringup` | launch 启动 |
| `rm_moveit2` + `rm_moveit2_config` | MoveIt2 规划控制 |

| `rm_gazebo` | Gazebo 仿真 |
| `rm_example` / `rm_doc` | 示例 / 文档 |

### 4.3 启动命令

```bash

ros2 launch rm_bringup rm_eco65_bringup.launch.py
```

**关键结论**：官方已把「驱动 + 模型 + MoveIt + Gazebo」全包了。**我们只需要在官方包之上，新增视觉、手眼标定、VLA 接口、数据采集、抓取编排这几块。**

## 五、自定义包划分（在官方包基础上新增 7 个）

```
robot_vla_ws/src/
├── ros2_rm_robot/          # 官方包（直接拷入，复用）
├── arm_perception/         # ① 四目深度相机驱动 + 目标检测/位姿

├── arm_calibration/        # ③ 运动学误差标定（可选进阶）

├── vla_bridge/             # ⑤ OpenPI ↔ ROS 接口（核心）
├── vla_data/               # ⑥ 示教数据采集 + 数据集建立
└── arm_grasp/              # ⑦ 抓取/放置流程编排
```

### 5.1 通信接口（含 VLA 专用话题）

| 类型 | 名称 | 数据 | 说明 |
|------|------|------|------|
| 话题 | `/joint_states` | `sensor_msgs/JointState` | 关节状态反馈（官方已提供） |
| 话题 | `/camera/image` | `sensor_msgs/Image` | 相机彩色图 |
| 话题 | `/camera/pointcloud` | `sensor_msgs/PointCloud2` | 点云 |
| 话题 | `/vla/instruction` | 自定义（String） | 语言任务指令 |
| 话题 | `/vla/image` | 自定义 | 相机图像（或多视角） |
| 话题 | `/vla/robot_state` | 自定义 | 关节角 + 末端位姿 + 夹爪状态 |
| 话题 | `/vla/action` | 自定义 | VLA 生成的动作（位姿增量 + 夹爪） |
| 服务 | `/fk` `/ik` | 自定义 srv | 正/逆运动学 |

### 5.2 坐标系（tf 树，2026-10-19 实测确认）

```
world → baselink → Link1 → Link2 → Link3 → Link4 → Link5 → Link6 → gripper
                       ↑
                camera_link（眼在手外 eye-to-hand，固定安装）
```

> ⚠️ **命名已按官方 `rm_description` 实测修正**，与手册写法完全不同，写代码务必照抄这一套：
> - 根坐标系 = **`baselink`**（不是 `base_link`，没有下划线）
> - 连杆 = **`Link1`~`Link6`**（不是 `link_1`，`L` 大写、无下划线）
> - **没有 `tool0`**，末端就是 **`Link6`**，夹爪直接装在 Link6 上
> - 关节名 = **`joint1`~`joint6`**
> - 零位实测：`baselink → Link6` 平移 `[−0.086, 0.021, 0.772]`，与 MDH 手算值吻合（x = a₂ = −0.086；z ≈ 0.1625+0.26+0.24+0.11 = 0.7725）

## 六、分模块开发路线

### 模块 1：arm_perception（视觉）
- **干嘛**：四目深度相机 → RGB 图 + 深度融合点云 → 目标检测 + 6D 位姿估计。
- **四目的好处**：多基线立体视觉，深度更密更稳，正好满足 VLA 需要的「图像 + 点云」。
- **输出**：目标物体在相机坐标系下的位姿（或直接给 VLA 用原始图像）。

### 模块 2：arm_handeye（手眼标定）
- **干嘛**：求「相机 ↔ 机械臂基座」的固定变换（Eye-to-Hand，AX=XB）。
- **流程**：标定板装到末端 → 机械臂多姿态移动 → 记录末端位姿 A + 相机看到标定板位姿 B → 求解 X。
- **误差指标**：粗抓取 < 20 mm，一般抓取 < 10 mm，精细抓取 < 5 mm（OpenPI 建议）。

### 模块 3：arm_calibration（运动学标定，可选）
- **干嘛**：修正 ECO65 装配误差、关节零位误差，进一步提高精度。

### 模块 4：arm_control（PID 底层控制）
- **干嘛**：接收 VLA/MoveIt 的动作目标（关节角或末端位姿增量），用 PID 精确跟踪。
- **关键**：关节空间 PID + 重力前馈 + 抗积分饱和；末端位姿增量 → IK → 关节目标 → PID。
- **力控（六维力版新增）**：可叠加末端力控（恒力贴合、柔顺插入），用于抓取/放置的接触阶段。
- **安全**：关节限位（用上面 ECO65 实参表）、速度/加速度限制、工作空间软限位。

### 模块 5：vla_bridge（VLA 接口，核心）
- **干嘛**：把 ROS 数据喂给 OpenPI，把 OpenPI 输出转成 ROS 控制指令。
- **输入**：`/vla/instruction` + `/vla/image` + `/vla/robot_state`。
- **输出**：`/vla/action`（末端位姿增量 + 夹爪动作）。
- **关键**：OpenPI 推理跑在独立 conda 环境，通过该 bridge 与 ROS 通信（解耦，不污染 ROS 环境）。

### 模块 6：vla_data（数据采集）
- **干嘛**：示教采集（拖动示教 / 手柄 / MoveIt 目标点），记录单条轨迹。六维力版首选**拖动示教**（手拽即录，无需编程，最自然）。
- **记录内容**：图像 + 关节角/速度 + 末端位姿 + 夹爪状态 + 语言指令 + 时间戳 + 成功/失败标签。
- **数据量**：基础验证每任务 20~50 条，初步微调 50~100 条，稳定抓取 100~300 条。

### 模块 7：arm_grasp（抓取编排）
- **干嘛**：把「识别 → 决策 → 执行」串成完整抓取/放置流程，含失败重试。

## 七、分阶段里程碑（融合我原 7 阶段 + OpenPI 8 阶段）

| 阶段 | 内容 | 验收标准 |
|------|------|---------|

## 八、关键技术点速查

| 概念 | 大白话 |
|------|--------|
| VLA 模型 | 视觉 + 语言 + 动作，看图和指令直接输出动作 |
| 双层控制 | VLA 决定「做什么」，PID 负责「做准」 |
| 动作空间 | 建议用「末端位姿增量 [Δx Δy Δz Δroll Δpitch Δyaw] + 夹爪」，易适配不同机械臂 |
| Eye-to-Hand | 相机固定在外，视野大稳定，适合桌面抓取 |
| 手眼标定 AX=XB | 求相机和手的固定关系，让「相机看到的」换成「手要动的」 |
| 阻尼最小二乘 | 求逆加阻尼，防止奇异位形卡死（你现有 MATLAB 已在用） |
| 六维力传感器 | 同时测 3 个方向的力 + 3 个方向的力矩，用来力控/拖动/夹持力反馈 |
| 拖动示教 | 手拽机械臂录轨迹，六维力版支持，采集 VLA 数据最自然 |
| 重力前馈 | 提前补偿重力，PID 只管道小误差 |

## 九、风险与待确认

1. **版本锁定**：官方只支持 Foxy，勿升级；OpenPI 推理独立 conda 环境，与 ROS 解耦。
2. **仿真统一**：官方用 Gazebo（`rm_gazebo` 开箱即用）；OpenPI 计划书提 Webots——**建议以 Gazebo 为主**，Webots 可选。
3. **视觉方案**：四目深度相机作为「RGB-D + 点云」源（Eye-to-Hand 优先），后期可加腕部相机双摄。
4. **夹爪**：V 型夹爪属二指夹爪一种，需带夹紧力反馈；六维力传感器可作为夹持力反馈来源，但夹爪本身仍要确认用睿尔曼官方夹爪还是自配。
5. **真机安全**：急停、软限位（用 ECO65 关节限位表）、低速起步、碰撞检测（六维力传感器可作额外碰撞检测源）。
6. **六维力标定**：更换六维力末端后须重新标定初始力与重心，否则力读数有偏置。
7. **待确认（剩余）**：夹爪型号、GPU 型号、四目相机型号、仿真引擎（Gazebo/Webots）。

**一句话总结**：在官方 `ros2_rm_robot`（驱动+模型+MoveIt+Gazebo 已就绪）之上，新增视觉、手眼标定、PID、VLA 接口、数据采集、抓取编排 7 个包，用「VLA 决策 + PID 执行」双层控制，实现 ECO65 六维力版的语言驱动智能抓取。
