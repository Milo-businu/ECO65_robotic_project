## 4. 踩过的坑

| # | 现象 | 指纹 | 根因 | 解决 |
|---|------|------|------|------|
| 1 | `from kdl_parser_py...` 失败 | 包不存在 | **ROS2 Foxy 未发布 KDL 的 Python 绑定**（那是 ROS1 遗产） | 改用纯 numpy 解析 URDF 自算 FK |
| 2 | IK 首跑卡在 6.15 mm | 解出的关节角跑到 ±42° | **零位（手臂竖直伸直）= q3=0 肘部奇异位形**，牛顿迭代从奇异点出发雅可比病态 | 初始猜测改为 `[0,0.2,0.3]` 离开奇异 |
| 3 | 阻尼系数失当 | 收敛极慢 | λ=0.05 对健康方向也压得太狠 | λ=1e-3 + 每步增量裁剪 ≤0.15 rad |
| 4 | 手算 MDH ≠ 实测 | 手算 [0.264,0.038,0.422] vs 实测 [−0.086,0.021,0.772] | 说明书 MDH 的"建模零位"与 URDF 零位不是同一姿态 | **一律以 URDF 为准，MDH 表只当参考** |

### 关于坑 3 的一次自我更正（值得记住）

我最初解释"λ=0.05 把步长放大导致过冲"——**这是错的**。DLS 每步增益是 `g(σ) = σ/(σ²+λ²)`，λ 越大曲线整体越低（越保守）。真实问题是它**对健康方向也压得过狠**，几百次迭代追不上目标。我主动更正了这个说法，并给出对照实验让用户验证。**工程里"更正自己"比"维护正确"更重要。**

## 5. 技术要点（小白版）

- **FK（正运动学）**：已知六个关节角度 → 算末端在哪。做法是把每根杆件的"固定偏移 × 绕轴旋转"写成 4×4 矩阵，一路连乘。
- **IK（逆运动学）**：反过来——想让末端到某处，反推六个关节该转多少。数值解法：算误差 → 用雅可比把误差换算成关节增量 → 迭代。
- **雅可比**：把"关节速度"换算成"末端速度"的比例表，是连接关节空间和任务空间的桥梁。
- **奇异位形**：某些姿态下雅可比"使不上劲"（某个方向无论怎么转关节都动不了）。手臂完全伸直就是典型的肘部奇异——像自行车脚蹬在死点，再用力也蹬不动。
- **阻尼最小二乘（DLS）**：求逆时加阻尼，避免奇异点附近步长爆炸。

### 高频追问

| 追问 | 回答要点 |
|------|---------|
| 为什么不用现成库（KDL/TracIK）？ | Foxy 未发布 Python 绑定；自研版只有 40 行、零依赖，且能逐层看到矩阵连乘过程，对学习和调试都更有价值。 |
| 奇异位形怎么在实际中规避？ | 初始猜测避开奇异点、轨迹规划避开伸直区、DLS 阻尼防步长爆炸。好消息：我们的 VLA 输出的是**位姿增量**，可用上一帧关节角当初始猜测，天然稳。 |
| 6.15 mm 到 0.0014 mm 之间改了什么？ | 三处：起始点离开奇异、阻尼 λ 由 0.05 调到 1e-3、每步关节增量裁剪 ≤0.15 rad；并诚实说明哪个是主因需要对照实验。 |
| MDH 表为什么不能直接用？ | 两套独立建模（SolidWorks 导出 vs 手工 DH），零位约定与符号约定（θ = q ± offset）都有歧义，教材之间都不统一。 |

## 7. 可迁移方法论

1. **依赖不可用 ≠ 路被堵死**——自研最小实现往往更可控、更可讲。
2. **数值方法要给出误差，而不是"看起来对"**——0.000 mm 比"跑通了"有价值一百倍。
3. **课本概念会在真机里以 bug 的形式出现**——奇异位形不是考点，是会让机器人乱动的事故。
4. **错了就当场更正**——更正记录本身就是工程能力的证据。
