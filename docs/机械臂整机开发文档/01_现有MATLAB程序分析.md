# 现有 MATLAB 程序分析（13 个文件）

> 这是一套「教学演示级」的机械臂运动学 + 可视化小工具包，不是产品级开发框架。
> 下面按功能分成 4 组，逐个讲清楚每个文件是干嘛的、完整不完整。

---

## 一、整体判断（先说结论）

这套代码**能跑、能看**，覆盖了机械臂最基础的两件事：

1. **正运动学**：知道每个关节的角度，算出末端（手）在哪儿、朝哪儿 ✅
2. **速度级逆解**：想把手往某个方向挪，反算出每个关节该怎么转 ✅
3. **画图**：把机器人用长方体/圆柱/坐标系实时画出来，能动画 ✅

但它**缺**一大堆整机开发要用的东西（见文末清单）：
位置级逆运动学、动力学、PID 控制、轨迹规划、夹爪、相机/感知、标定、6 关节……

所以：**这套代码是你打基础的好教材，但离「抓取物体的整机」还差很远。** 后面要补的东西，正好就是我们在开发方案里要规划的模块。

## 二、13 个文件逐个讲

### 第 1 组：数学工具（2 个）——旋转的「翻译官」

| 文件 | 作用 | 大白话 |
|------|------|--------|
| `hat.m` | 把 3×1 向量变成 3×3「叉乘矩阵」 | 把「绕轴转」这种叉乘运算，改写成矩阵乘法，方便后续推导 |
| `rot.m` | 用 Rodrigues 公式，把「绕某轴转 θ 角」变成 3×3 旋转矩阵 | 给一个转轴和角度，算出旋转矩阵 |

**要点**：`rot` 用的就是欧拉-罗德里格斯公式
`R = I + sinθ·hat(k) + (1-cosθ)·hat(k)²`
这正是你学过的「旋转」的核心。绕轴转角度 → 一个 3×3 矩阵。

---

### 第 2 组：运动学（3 个）——机器人的「算盘」

| 文件 | 作用 | 大白话 |
|------|------|--------|
| `Forward_Kinematics.m` | **正运动学**：输入 DH 参数表，输出每根连杆的位姿（齐次变换矩阵） | 给关节角，算出手在哪儿、朝哪儿 |
| `Jacobian.m` | **几何雅可比**：6×n 矩阵，把「关节速度」换算成「末端速度」 | 末端速度 = 雅可比 × 关节速度，这是控制机器人的核心桥梁 |
| `JacobianArbitraryFrame.m` | 任意连杆上某个点的雅可比 | 不只算指尖，还能算夹爪上某一点的速度 |

**要点**（呼应你的学习）：
- `Forward_Kinematics` 用的是**标准 DH 参数**（每列是 `d, θ, a, α`），逐列连乘得到位姿。
- 里面用了一次 **SVD 奇异值分解**，把旋转部分「强制正交化」——这是数值上防误差累积的小技巧。
- `Jacobian` 里旋转关节贡献 `[cross(z, p_e-p_pre); z]`，移动关节贡献 `[z; 0]`。这就是你之前学的「几何雅可比」两种列。

### 第 3 组：画图（7 个）——机器人的「皮」

| 文件 | 作用 |
|------|------|
| `createCuboid.m` | 画长方体（也支持梯形面） |
| `createCylinder.m` | 画圆柱（也支持圆锥、椭圆柱、椭圆锥） |
| `createEllipsoid.m` | 画椭球（也支持球） |
| `create3DFrame.m` | 画一个 X(红)Y(绿)Z(蓝) 三色坐标系，用来标方向 |
| `combineRigidBodies.m` | 把几个刚体拼成一个整体 |
| `attachPrefix.m` | 给标签加前缀（如 `X_`、`Y_`） |
| `updateRigidBody.m` | **更新刚体姿态**（旋转 + 平移所有顶点）——动画的关键 |

**要点**：这套画图思路很规整——
- 每个图形函数都返回一个结构体，里面存了 `R`（朝向）、`t`（位置）、`bodies`（patch 句柄）、`labels`（标签）。
- `updateRigidBody` 的核心就两行：
  ```
  R12 = R * handle.R';          % 新的相对旋转
  t12 = t - R12 * handle.t;     % 新的相对平移
  ```
  然后把所有顶点用 `V*R12' + t12` 变换一遍。这就是「物体动起来」的底层原理。

### 第 4 组：演示（1 个）

| 文件 | 作用 |
|------|------|
| `test_IDK.m` | 主程序：搭一个 3 关节机械臂，用手柄（Xbox）控制末端速度，实时动画 |

**它具体干了什么**（顺序）：
1. 定义 3 个关节（`Jtype=[0 0 0]` 全是旋转关节）、DH 参数表、初始关节角。
2. 用 `Forward_Kinematics` 算出各连杆位姿，用画图函数把机器人画出来。
3. 进入 `while 1` 循环：读取手柄摇杆 → 得到末端期望速度 `v_e`。
4. 用**阻尼最小二乘**解出关节速度：
   ```
   q_dot = Jᵀ (J Jᵀ + k²I)⁻¹ v_e
   ```
   这就是你之前见过的「雅可比转置 / 阻尼最小二乘」逆解，`k` 是阻尼系数，用来防止奇异性（机器人卡死时矩阵求逆失败）。
5. 更新关节角 → 重新算正运动学 → 用 `updateRigidBody` 刷新画面。

> IDK 这个文件名 = Inverse Differential Kinematics（逆微分运动学，也就是速度级逆解）。

## 三、读代码发现的小瑕疵（正好当学习点）

1. **关节类型不一致**：`test_IDK.m` 里 `Jtype=[0 0 0]` 全标成旋转关节，但第 3 个关节实际是用 `d`（平移）驱动的（`DH(1,3)=q(3)`）。
   → 这正是你之前遇到过的「某个数落在表格哪一格，是当初建模时决定的」——要读约定，不要死记位置。

2. **标签复制笔误**：`create3DFrame.m` 里
   ```matlab
   h_y.labels = attachPrefix('Y_', h_x.labels);   % 用了 h_x
   h_z.labels = attachPrefix('Z_', h_x.labels);   % 用了 h_x
   ```
   两处都写成了 `h_x.labels`，应该是笔误（不影响显示，但不符合本意）。
